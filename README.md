# PARADOX MUSIC — Telegram bot

Готовая основа музыкального Telegram-бота на Node.js 20+.

## Что умеет

- Ищет песни и исполнителей через Apple iTunes Search API.
- Ищет совпадения по фразе из песни через LRCLIB (показывает название и исполнителя, не публикует текст песни).
- Распознаёт музыку из Telegram voice, audio, video и video note через AudD.
- Показывает ссылки на Apple Music / Spotify, если они доступны в ответе распознавания.
- Может отправлять аудиофайл из локального каталога `music/`, если это ваша запись или у вас есть право её распространять.
- Принимает ссылки и предлагает распознавание через отправленный фрагмент. Не извлекает и не скачивает защищённую музыку с YouTube, TikTok или Instagram.

## 1. Создай Telegram-бота

1. Открой Telegram и найди `@BotFather`.
2. Отправь `/newbot`.
3. Задай имя и username.
4. Скопируй токен.

## 2. Получи ключ распознавания

Для распознавания аудио нужен API-токен AudD: https://audd.io/
Условия, тарифы и лимиты проверь на сайте сервиса. Без `AUDD_TOKEN` поиск по названию будет работать, а распознавание аудио — нет.

## 3. Настрой проект

```bash
npm install
```

Скопируй `.env.example` в `.env` и заполни:

```env
BOT_TOKEN=токен_от_BotFather
AUDD_TOKEN=токен_AudD
BOT_NAME=PARADOX MUSIC
MAX_FILE_MB=18
```

Не отправляй `.env` другим людям и не загружай его в GitHub.

## 4. Запусти

```bash
npm start
```

В консоли должно появиться сообщение `PARADOX MUSIC started as @...`.

## 5. Размещение на Render

Создай **Background Worker** (не Web Service):
- Build Command: `npm install`
- Start Command: `npm start`
- Runtime: Node
- Добавь `BOT_TOKEN`, `AUDD_TOKEN`, `BOT_NAME`, `MAX_FILE_MB` в Environment.

Важно: локальные файлы на Render могут исчезнуть при redeploy. Для постоянного каталога музыки используй Persistent Disk или внешний объектный storage. Не сохраняй токены в исходниках.

## 6. Свой легальный музыкальный каталог

Положи MP3 в папку `music/`, затем добавь запись в `catalog.json`:

```json
[
  {
    "title": "Название композиции",
    "artist": "Исполнитель",
    "file": "music/track.mp3",
    "rights": "Право на распространение подтверждено"
  }
]
```

Бот отправит совпавший файл вместе с результатами поиска. Добавляй только музыку, которую создал сам или на распространение которой у тебя есть разрешение.

## Ограничения и заметки

- Telegram Bot API ограничивает скачивание файлов ботом; проект дополнительно ограничивает входящий файл параметром `MAX_FILE_MB`.
- Для видео бот извлекает аудиодорожку и анализирует до 90 секунд.
- Ссылки на соцсети не скачиваются и не обходят защиту платформ.
- API сторонних сервисов могут менять тарифы, лимиты и доступность.
- Перед публичным запуском добавь rate limiting, мониторинг расходов API и политику конфиденциальности.
